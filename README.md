# AI Kakao

Aplikasi Android untuk memeriksa kesehatan buah kakao lewat foto. Cukup potret
buahnya, hasilnya langsung keluar di HP — tidak perlu sinyal.

Projek capstone, Program Studi Informatika, Institut Teknologi Sains Bandung.

---

## Unduh

Ambil berkas `.apk` terbaru di halaman **[Releases](../../releases/latest)**.

## Cara pasang

1. Unduh berkas `.apk` dari tautan di atas.
2. Buka berkas yang terunduh. Kalau Android menolak, pilih **Setelan** lalu
   izinkan pasang aplikasi dari sumber ini. Ini wajar — aplikasinya tidak lewat
   Play Store, jadi Android minta izin dulu.
3. Buka aplikasinya, lalu foto buah kakao.

Butuh **Android 8.0 ke atas**. Ukuran berkas sekitar 33 MB.

## Yang perlu diketahui

- Ini **prototipe**, bukan aplikasi jadi. Hasilnya bisa salah, jadi jangan
  dipakai sebagai satu-satunya dasar untuk mengambil tindakan di kebun.
- Semua data tinggal di HP masing-masing. Aplikasinya tidak mengirim foto ke
  mana pun; satu-satunya yang butuh internet adalah tampilan cuaca di beranda.
- Belum ditandatangani sertifikat rilis, jadi Android akan menampilkan
  peringatan saat memasang.
